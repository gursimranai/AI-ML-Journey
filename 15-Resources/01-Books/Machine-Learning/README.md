# Machine Learning Books

This directory contains books and reading resources for learning **Machine Learning (ML)**, from fundamental concepts and classical algorithms to advanced modeling techniques.

## Topics Covered

Resources in this directory may cover:

- Introduction to Machine Learning and learning paradigms
- Supervised, unsupervised, and reinforcement learning
- Data preprocessing and feature engineering
- Linear and logistic regression
- Classification and regression algorithms
- Decision trees, random forests, and ensemble learning
- Support Vector Machines (SVM)
- k-Nearest Neighbors (KNN)
- Clustering algorithms
- Dimensionality reduction and feature selection
- Model evaluation and validation
- Bias, variance, overfitting, and underfitting
- Hyperparameter tuning and model selection
- Probability, statistics, and optimization for ML
- Feature importance, interpretability, and responsible ML
- Practical ML workflows and deployment fundamentals

## Book Trackers

Each book's Markdown tracker is the primary record of its chapters, topics, and reading progress.

Use the tracker to record:

- Chapters and topics completed
- Important concepts, assumptions, and mathematical foundations
- Algorithm intuition and working principles
- Key equations and their meanings
- Implementation exercises and experiments
- Topics that require revision
- Practical applications and personal notes

Keep detailed, book-specific information in the corresponding tracker rather than duplicating it in this README.

## Recommended Learning Method

1. Understand the problem each algorithm is designed to solve.
2. Learn its assumptions, intuition, and mathematical foundation.
3. Work through a small example by hand.
4. Implement the algorithm using Python and relevant libraries.
5. Evaluate it with appropriate metrics and validation techniques.
6. Compare it with alternative approaches and examine its limitations.
7. Document observations and revisit concepts that remain unclear.

## Organization Guidelines

- Preserve existing book folders and their trackers.
