# Python Books

This directory contains books and reading resources for learning **Python programming**, from core language fundamentals to advanced features, software development practices, and Python internals.

## Topics Covered

Resources in this directory may cover:

- Python installation and development environments
- Variables, data types, operators, and expressions
- Conditional statements and loops
- Strings and built-in collections
- Functions, arguments, scope, and recursion
- Comprehensions, iterators, and generators
- Modules, packages, and imports
- Exception handling
- Object-oriented programming
- Decorators and context managers
- Type hints and modern Python features
- File handling and serialization
- Standard library modules
- Virtual environments and package management
- Testing, debugging, and code quality
- Concurrency, asynchronous programming, and performance
- Advanced Python features and language internals

Use the tracker to record:

- Chapters, units, and topics covered

Keep detailed, book-specific progress in the corresponding tracker rather than duplicating it in this README.

## Recommended Learning Method

1. Understand each concept before memorizing syntax.
2. Run code examples and modify them to observe the results.
3. Practice with small problems after learning a new topic.
4. Explore relevant built-in functions and standard-library modules.
5. Learn readable, maintainable Python coding practices.
6. Build small projects to apply concepts together.
7. Revisit difficult topics and document common mistakes.
