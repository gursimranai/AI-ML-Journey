# 📚 Books Library

The Books Library contains book-based learning resources for programming, data structures and algorithms, machine learning, and artificial intelligence.

Each book has its own folder and Markdown tracker. The tracker records the book's topics, chapters or units, and learning progress. This structure keeps book resources organized and makes it easier to monitor progress through each book.

## 🗂️ Book Folder Organization

Keep each book's resources together in its existing folder.

A book folder may contain:

- A Markdown tracker for topics, chapters, or units.
- Personal notes and chapter summaries.
- Code examples and exercises.
- Supporting diagrams or reference materials.
- Other resources directly related to the book.

Do not create duplicate trackers when an existing Markdown file already serves this purpose.

## 📊 Book Trackers

Each book's Markdown tracker is the source of truth for its learning progress.

Use the tracker to:

- List topics, chapters, or units in the book.
- Mark completed and pending sections.
- Track revision and practice where relevant.
- Link to notes, exercises, or code examples.
- Record useful observations while studying.

Keep book-specific progress inside the relevant book folder. The category README should provide navigation rather than duplicate the detailed tracker.

## 📝 Resource Documentation

Where relevant, document each book with its verified title, author, edition, official source, and subject.

Keep descriptions concise, and link to publisher pages or official resources when available. Do not invent bibliographic details.

## ⚖️ Copyright and Licensing

- Respect the copyright and license of each book.
- Do not upload or redistribute copyrighted books without authorization.
- Prefer official publisher links when redistribution is not permitted.
- Keep your own notes and summaries distinguishable from the original material.

## 💡 Best Practices

- Preserve existing book folders and tracker files.
- Use consistent, descriptive filenames.
- Update a book's tracker as you progress.
- Add new book links to the relevant subject README.
- Avoid duplicating the same resource across categories.
- Verify relative links whenever files or folders are renamed.
