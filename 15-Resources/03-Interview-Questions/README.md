## Recommended Question Format

Where appropriate, document each question using this structure:

1. **Question:** State the problem clearly.
2. **Concept:** Identify the underlying principle.
3. **Answer:** Explain the reasoning in your own words.
4. **Example:** Provide a practical example, formula, or code snippet.
5. **Complexity:** Include time and space complexity for algorithmic questions where relevant.
6. **Follow-up:** Add a deeper question or variation.
7. **Common mistake:** Explain a frequent misconception or incorrect approach.

## Recommended Difficulty Levels

- **Beginner:** Definitions, syntax, foundational concepts, and straightforward examples.
- **Intermediate:** Application, comparisons, implementation, and multi-step reasoning.
- **Advanced:** Trade-offs, optimization, system design, mathematical depth, and edge cases.

## Preparation Guidelines

- Attempt questions before consulting solutions.
- Explain concepts aloud as if answering an interviewer.
- Write and test code instead of relying only on theoretical answers.
- Practice edge cases and analyze algorithmic complexity.
- Revisit incorrect answers and record the underlying knowledge gap.
- Include follow-up questions to strengthen conceptual depth.
- Keep answers accurate, concise, and supported by reasoning.

## Organization Guidelines

- Keep each subject's questions in its corresponding folder.
- Separate conceptual questions from coding problems when useful.
- Use consistent Markdown formatting and descriptive filenames.
- Cite sources when adapting questions from external materials.
- Respect copyright and licensing terms.
- Link to relevant notebooks and projects in `AI-ML-Journey` when they provide useful practical examples.
