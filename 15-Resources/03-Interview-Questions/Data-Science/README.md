# Data Science Interview Questions

This directory contains interview preparation questions covering the concepts, techniques, tools, and practical workflows used in Data Science.

The focus is on developing the ability to analyze data, select appropriate methods, interpret results, and communicate data-driven insights clearly.

## Topics Covered

### 1. Data Science Fundamentals
- What is Data Science, and how does it differ from Data Analytics?
- What are the stages of a typical Data Science workflow?
- How do descriptive, diagnostic, predictive, and prescriptive analytics differ?
- What are features, labels, observations, and datasets?
- How do batch and streaming data differ?

### 2. Python for Data Science
- Python data structures and comprehensions
- Functions, iterators, and generators
- NumPy arrays, vectorization, and broadcasting
- Pandas Series and DataFrames
- Data filtering, grouping, merging, and reshaping
- Writing efficient, readable data-processing code

### 3. Data Cleaning and Preprocessing
- How do you identify and handle missing values?
- How do you detect duplicates and inconsistent records?
- How should categorical variables be encoded?
- What is the difference between normalization and standardization?
- How do you detect and treat outliers?
- What is data leakage, and how can it be prevented?

### 4. Exploratory Data Analysis (EDA)
- What is EDA, and why is it important?
- How do you inspect a new dataset?
- Which plots are suitable for different variable types?
- How do you identify distributions, relationships, and anomalies?
- What is the difference between correlation and causation?
- How do you communicate findings through visualizations?

### 5. Probability and Statistics
- Mean, median, mode, variance, and standard deviation
- Conditional probability and Bayes' theorem
- Probability distributions and expected value
- Sampling and the Central Limit Theorem
- Confidence intervals and hypothesis testing
- p-values and statistical significance
- Type I and Type II errors
- Correlation and covariance

### 6. SQL and Data Retrieval
- Joins, aggregation, and filtering
- Subqueries and Common Table Expressions
- Window functions and ranking
- Finding duplicates and missing values
- Top-N queries and group-wise analysis
- Query optimization fundamentals

### 7. Machine Learning Fundamentals
- Supervised versus unsupervised learning
- Classification versus regression
- Training, validation, and test sets
- Overfitting, underfitting, and the bias–variance trade-off
- Cross-validation and model selection
- Feature selection and feature engineering
- Hyperparameter tuning

### 8. Model Evaluation
- Accuracy, precision, recall, and F1-score
- Confusion matrices and ROC-AUC
- MAE, MSE, RMSE, and \(R^2\)
- Class imbalance and metric selection
- Threshold selection and business trade-offs
- Evaluating models on unseen data

### 9. Practical and Scenario-Based Questions
- How would you investigate a dataset with many missing values?
- How would you identify the reasons for declining sales?
- How would you measure the success of a product feature?
- How would you investigate an unexpected change in a metric?
- How would you choose an evaluation metric for an imbalanced dataset?
- How would you explain a statistical result to a non-technical stakeholder?

## Recommended Question Format

For each question, document:

- **Question:** The exact interview question.
- **Difficulty:** Beginner, Intermediate, or Advanced.
- **Concepts tested:** The underlying knowledge.
- **Answer:** A clear explanation supported by reasoning.
- **Example:** A practical scenario, calculation, SQL query, or Python snippet where relevant.
- **Follow-up questions:** Deeper variations an interviewer might ask.

## Preparation Guidelines

- Solve practical questions using real or sample datasets.
- Explain why a method is appropriate, including its limitations.
- Support statistical conclusions with sound reasoning.
- Practice Python, Pandas, SQL, and visualization tasks.
- Review incorrect answers and revisit the underlying concepts.
- Communicate assumptions and findings clearly.
