# Data Structures and Algorithms Interview Questions

This directory contains interview preparation questions covering data structures, algorithms, complexity analysis, and problem-solving techniques.

The goal is to develop strong algorithmic thinking, write correct and efficient code, and explain the reasoning behind each solution.

## Topics Covered

### 1. Complexity Analysis
- What are time and space complexity?
- Explain Big O, Big Omega, and Big Theta notation.
- How do best, average, and worst cases differ?
- What is amortized analysis?
- How do you analyze nested loops and recursive functions?
- What is the time complexity of common operations on arrays, lists, hash tables, and trees?

### 2. Arrays and Strings
- Reverse an array or string.
- Find the largest, smallest, or second-largest element.
- Remove duplicates from a sorted array.
- Find a missing number or repeated element.
- Solve the Two Sum problem.
- Explain the two-pointer technique.
- Explain the sliding-window technique.
- Find the maximum subarray sum.
- Check whether two strings are anagrams.

### 3. Linked Lists
- What is the difference between singly and doubly linked lists?
- Reverse a linked list iteratively and recursively.
- Detect a cycle in a linked list.
- Find the middle node.
- Merge two sorted linked lists.
- Remove the nth node from the end.
- Explain the slow-and-fast pointer technique.

### 4. Stacks and Queues
- Implement a stack and a queue.
- Compare stacks and queues.
- Evaluate postfix expressions.
- Check balanced parentheses.
- Implement a queue using stacks.
- Explain monotonic stacks and their applications.
- What is a deque, and when is it useful?

### 5. Hashing
- How does a hash table work?
- What is a hash collision?
- Compare common collision-resolution strategies.
- Find duplicate elements efficiently.
- Count element frequencies.
- Explain the relationship between hashing and average-case lookup complexity.

### 6. Searching and Sorting
- Explain linear search and binary search.
- What conditions are required for binary search?
- Compare bubble, selection, and insertion sort.
- Explain merge sort and quicksort.
- What is the average and worst-case complexity of quicksort?
- What is a stable sorting algorithm?
- When is counting sort useful?

### 7. Recursion and Backtracking
- What are base cases and recursive cases?
- How does recursion use the call stack?
- Compare recursion and iteration.
- Generate permutations and combinations.
- Solve subset and combination-sum problems.
- Explain backtracking with a maze or N-Queens example.
- How do you identify opportunities for pruning?

### 8. Trees and Binary Search Trees
- Explain binary trees and binary search trees.
- Compare preorder, inorder, and postorder traversal.
- Explain level-order traversal.
- Find the height or diameter of a binary tree.
- Check whether a tree is balanced.
- Find the lowest common ancestor.
- Explain tree insertion, deletion, and search.
- What are heaps and priority queues?

### 9. Graphs
- Compare adjacency lists and adjacency matrices.
- Explain breadth-first search (BFS) and depth-first search (DFS).
- Detect cycles in directed and undirected graphs.
- Explain topological sorting.
- Find shortest paths in unweighted and weighted graphs.
- Explain Dijkstra's algorithm and its limitations.
- What is a minimum spanning tree?
- Explain disjoint-set union (Union-Find).

### 10. Greedy Algorithms and Dynamic Programming
- What is the greedy-choice property?
- When does a greedy approach fail?
- Explain memoization and tabulation.
- Identify overlapping subproblems and optimal substructure.
- Solve Fibonacci, climbing stairs, and coin-change problems.
- Explain the knapsack problem.
- Solve longest common subsequence and longest increasing subsequence problems.

### 11. Bit Manipulation
- Explain bitwise AND, OR, XOR, and NOT.
- How do bit shifts work?
- Check whether a number is a power of two.
- Find a unique element using XOR.
- Set, clear, and toggle a bit.

### 12. Problem-Solving Patterns
- Two pointers
- Sliding window
- Prefix sums
- Binary search on an answer
- Fast and slow pointers
- Monotonic stack
- Heap-based selection
- Graph traversal
- Dynamic programming states
- Union-Find

## Recommended Question Format

For every coding problem, record:

- **Problem statement:** Clearly define the input and expected output.
- **Difficulty:** Easy, Medium, or Hard.
- **Approach:** Explain the core idea.
- **Algorithm:** Describe the steps.
- **Implementation:** Provide readable, tested code.
- **Complexity:** Analyze time and auxiliary space.
- **Edge cases:** Test empty inputs, duplicates, boundaries, and invalid cases where applicable.
- **Alternative approaches:** Compare solutions when useful.

## Preparation Guidelines

- Attempt each problem independently before viewing a solution.
- Start with a straightforward approach, then optimize it.
- Explain the algorithm before writing code.
- Test normal cases, edge cases, and boundary conditions.
- Analyze complexity and justify trade-offs.
- Revisit problems you could not solve and document the underlying pattern.
- Practice implementing core data structures from scratch.

Use Python for implementation practice when appropriate, while focusing on the underlying algorithm rather than language-specific tricks.
