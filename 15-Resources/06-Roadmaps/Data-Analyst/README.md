# Data Analyst Roadmap

This roadmap outlines a structured learning path for becoming a Data Analyst who can collect, clean, analyze, visualize, and communicate data-driven insights.

The focus is on developing practical skills in spreadsheets, SQL, Python, statistics, data visualization, and business problem-solving.

## 1. Spreadsheet Fundamentals

Learn to organize, manipulate, and analyze structured data using spreadsheet software.

Topics include:
- Workbook and worksheet management
- Data types and cell references
- Sorting and filtering
- Conditional formatting
- Common formulas and functions
- Logical functions such as `IF`, `AND`, and `OR`
- Lookup functions such as `XLOOKUP` and `INDEX`/`MATCH`
- Text and date functions
- Pivot tables and pivot charts
- Data validation and data cleaning

**Tools:** Microsoft Excel or Google Sheets.

**Practical work:** Clean a messy spreadsheet, summarize business performance, and create a report using pivot tables and charts.

## 2. SQL and Databases

SQL is a core skill for retrieving and analyzing data stored in relational databases.

Topics include:
- Tables, rows, columns, and data types
- Primary keys and foreign keys
- `SELECT`, `WHERE`, and `ORDER BY`
- Filtering with `IN`, `BETWEEN`, and pattern matching
- Aggregate functions and `GROUP BY`
- `HAVING` and conditional expressions
- Inner, left, right, and full joins
- Subqueries and Common Table Expressions (CTEs)
- Window functions and ranking
- Date and string functions
- `CASE` expressions
- NULL handling
- Query optimization fundamentals

**Tools:** PostgreSQL, MySQL, SQL Server, or SQLite.

**Practical work:** Analyze sales, customers, products, and transactions using increasingly complex SQL queries.

## 3. Statistics and Probability

Learn to interpret data correctly and avoid misleading conclusions.

Topics include:
- Mean, median, and mode
- Range, variance, and standard deviation
- Percentiles and quartiles
- Probability fundamentals
- Common probability distributions
- Sampling and sampling bias
- Confidence intervals
- Hypothesis testing
- Correlation and covariance
- Regression fundamentals
- Statistical significance and practical significance
- A/B testing
- Common statistical pitfalls

**Practical work:** Analyze a dataset, explain its statistical patterns, and distinguish correlation from causation.

## 4. Python for Data Analysis

Use Python to automate repetitive tasks and analyze larger datasets.

Topics include:
- Python fundamentals
- Functions, loops, and data structures
- File handling and exception handling
- Modules and virtual environments
- NumPy arrays and vectorized operations
- Pandas Series and DataFrames
- Filtering, sorting, grouping, and aggregation
- Combining datasets with joins and concatenation
- Missing-value handling
- Dates, strings, and categorical data
- Data cleaning and preprocessing
- Reusable analysis scripts

**Practical work:** Convert a manual spreadsheet workflow into a reproducible Python analysis.

## 5. Exploratory Data Analysis

EDA helps reveal patterns, anomalies, relationships, and potential data-quality problems before drawing conclusions.

Topics include:
- Understanding dataset structure
- Data-quality checks
- Missing values and duplicates
- Outlier investigation
- Univariate and multivariate analysis
- Distribution analysis
- Group comparisons
- Correlation analysis
- Feature relationships
- Visual exploration
- Writing evidence-based observations

**Tools:** Pandas, Matplotlib, Seaborn, and spreadsheet charts.

**Practical work:** Perform a complete EDA on a real dataset and communicate the most important findings.

## 6. Data Visualization

Learn to select appropriate visualizations and communicate findings clearly.

Topics include:
- Bar and column charts
- Line charts and time-series trends
- Histograms and box plots
- Scatter plots
- Heatmaps
- Distribution and composition charts
- Choosing suitable chart types
- Labels, scales, legends, and annotations
- Color and accessibility
- Avoiding misleading visualizations
- Dashboard layout and information hierarchy

**Practical work:** Build a report or dashboard that answers specific analytical questions rather than merely displaying charts.

## 7. Business and Domain Understanding

A strong analyst understands the decision behind the analysis.

Topics include:
- Translating business questions into analytical questions
- Defining measurable objectives
- Key Performance Indicators (KPIs)
- Revenue, profit, growth, retention, and conversion
- Customer segmentation
- Funnel analysis
- Cohort and retention analysis
- Operational performance
- Requirements gathering
- Communicating assumptions and limitations

**Practical work:** Analyze a business scenario and recommend actions supported by evidence.

## 8. Business Intelligence and Dashboards

Learn to build interactive reports for stakeholders.

Topics include:
- Data sources and refresh workflows
- Data modeling fundamentals
- Relationships between tables
- Calculated columns and measures
- Interactive filters and slicers
- Drill-down and drill-through
- Dashboard design
- Performance considerations
- Publishing and sharing reports

**Tools:** Power BI or Tableau. Choose one initially rather than trying to master both simultaneously.

**Practical work:** Build an interactive dashboard with clearly defined KPIs and useful filters.

## 9. Data Quality and Analytical Reliability

Ensure that conclusions are based on trustworthy data and reproducible methods.

Topics include:
- Data validation
- Duplicate and missing-record handling
- Consistent units and formats
- Outlier investigation
- Data lineage and source documentation
- Reproducible queries and scripts
- Version control with Git
- Privacy and responsible data handling
- Communicating uncertainty

## 10. Portfolio Projects

Build projects that demonstrate your ability to answer real questions.

### Beginner
- Spreadsheet sales analysis
- SQL-based customer analysis
- Exploratory analysis of a public dataset

### Intermediate
- End-to-end Python data cleaning and analysis
- Business KPI dashboard
- Customer retention or cohort analysis

### Advanced
- Multi-table business analysis using SQL and Python
- Automated reporting pipeline
- A/B test analysis with a clear explanation of assumptions and limitations

For every project, include the problem statement, dataset source, methodology, key findings, visualizations, limitations, and recommendations.

## 11. Career Preparation

Prepare to demonstrate both technical ability and analytical communication.

- Practice SQL from basic filtering through joins, CTEs, and window functions.
- Strengthen Excel or Google Sheets skills.
- Review statistics and analytical reasoning.
- Practice explaining charts and business metrics.
- Prepare case studies involving ambiguous business questions.
- Maintain a portfolio of reproducible projects.
- Write clear project documentation and a concise resume.
- Learn to explain how your findings could influence a decision.

## Suggested Learning Order

```text id="n8p4dr"
Spreadsheets
     ↓
SQL and Database Fundamentals
     ↓
Statistics and Probability
     ↓
Python and Pandas
     ↓
Exploratory Data Analysis
     ↓
Data Visualization
     ↓
Power BI or Tableau
     ↓
Business Case Studies and Portfolio
```

You can learn SQL and statistics alongside spreadsheets. Practice with real datasets throughout the roadmap instead of waiting until the end to build projects.
