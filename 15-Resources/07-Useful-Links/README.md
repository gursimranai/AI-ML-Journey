# Useful Links

This section contains a curated collection of websites, documentation, learning platforms, developer tools, open-source communities, and research resources useful throughout the AI/ML learning journey.

Resources are organized by purpose so that you can quickly find reliable references for learning, practice, development, and research.

## How to Use This Collection

- Use **official documentation** to understand tools and verify their behavior.
- Use **free courses** when you need a structured introduction to a topic.
- Use **practice platforms** to strengthen programming and problem-solving skills.
- Use **dataset platforms** to find suitable data for experiments and projects.
- Use **open-source platforms** to study real-world code and contribute to projects.
- Use **research platforms** to explore new methods and understand current developments.
- Use **developer tools** to improve your workflow and build reproducible projects.

## Resource Selection Guidelines

When adding a new resource, consider:

1. **Relevance:** Does it support programming, mathematics, data science, AI/ML, or software engineering?
2. **Reliability:** Is the source maintained by an official organization, recognized community, or credible author?
3. **Accessibility:** Are the materials free, paid, or partially available? State this when relevant.
4. **Quality:** Does the resource provide accurate explanations, practical examples, or useful references?
5. **Maintenance:** Are its documentation, links, and learning materials still current?
6. **Licensing:** Are downloaded materials permitted to be shared or redistributed?

Avoid adding links simply to increase the number of resources. Prioritize usefulness and quality.
