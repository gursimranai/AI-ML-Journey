## How to Use Documentation Effectively

### 1. Start with the official tutorial

Learn the basic workflow before diving into the complete API reference. Tutorials usually provide context and explain how different components fit together.

### 2. Search for the exact API

When using a function, class, or method, check its official reference for:

- Parameters and accepted data types
- Default values and optional arguments
- Return values and output shapes
- Exceptions and error conditions
- Supported versions and compatibility requirements
- Examples and related methods

### 3. Run examples yourself

Do not rely only on reading code. Execute small examples in a notebook or script, inspect the output, and modify one parameter at a time.

### 4. Check version compatibility

Documentation may differ across library versions. Check your installed version before copying an example.

```python
import numpy as np
import pandas as pd
import sklearn

print("NumPy:", np.__version__)
print("Pandas:", pd.__version__)
print("Scikit-learn:", sklearn.__version__)
```

For Python packages, you can also inspect installed versions from the terminal:

```bash
python --version
python -m pip show numpy pandas scikit-learn
```

### 5. Prefer official examples over unexplained snippets

When a blog post or AI-generated answer provides code, use the official documentation to confirm that the API exists, the arguments are valid, and the approach is appropriate for your installed version.

### 6. Record useful findings

For concepts that are difficult to remember, document the key behavior, a minimal working example, common errors, and a link to the relevant reference page in your repository notes.

## A Documentation-First Workflow

For any new library or API:

1. Identify the task you want to solve.
2. Open the official tutorial or quickstart.
3. Find the relevant function or class reference.
4. Check examples, parameters, outputs, and version requirements.
5. Run a minimal reproducible example.
6. Test edge cases and error handling.
7. Save the working example and reference link in your notes.
8. Verify the behavior again when upgrading dependencies.
