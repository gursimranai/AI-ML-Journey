# 📚 Resources Library

Welcome to the **Resources Library** of the AI-ML-Journey repository.

This directory contains a curated collection of books, cheat sheets, interview questions, study materials, research papers, career roadmaps, and useful learning links for programming, data science, machine learning, and artificial intelligence.

The purpose of this library is to keep learning resources organized, accessible, and easy to navigate throughout the journey from fundamentals to advanced AI engineering.

## 📂 Directory Structure

| Folder | Description |
|---|---|
| [01-Books](01-Books/README.md) | Books and book-related learning resources for programming, DSA, machine learning, and AI. |
| [02-Cheat-Sheets](02-Cheat-Sheets/README.md) | Quick-reference sheets for programming languages, mathematics, libraries, and development tools. |

| [07-Useful-Links](07-Useful-Links/README.md) | Official documentation, courses, developer tools, datasets, practice platforms, and research resources. |

## 🧭 How to Use This Library

- Use books and course materials to develop a strong conceptual foundation.
- Use cheat sheets for quick revision and reference while coding.
- Practice interview questions to strengthen problem-solving and technical knowledge.
- Read research papers to understand important methods and developments in AI.
- Follow roadmaps to structure your learning and career preparation.
- Use official documentation and reliable external resources to deepen your understanding.

## 🗂️ Organization Guidelines

- Store every resource in the category that best matches its purpose.
- Use descriptive filenames in `kebab-case`.
- Keep a README in each category and relevant subfolder.
- Add links to actual files from the corresponding README.
- Prefer official documentation and trustworthy educational sources.
- Include source links and attribution when required.
- Avoid duplicate files and broken relative links.
- Keep personal notes and summaries distinct from original third-party materials.

## 📝 Resource Documentation

Where relevant, document each resource with:

- **Title:** Name of the book, document, course, or paper.
- **Author or source:** Creator, publisher, or official website.
- **Topics:** Main concepts covered.
- **Purpose:** How the resource supports learning.
- **Link:** Relative path for local files or the original external URL.

Only include details that can be verified from the resource.

## ⚖️ Copyright and Licensing

Respect the licenses and usage restrictions of books, papers, courses, and other materials. Do not redistribute copyrighted content without permission. Prefer linking to official sources when a resource cannot legally be hosted in the repository.
