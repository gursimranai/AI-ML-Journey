# Deep Learning Cheat Sheets

This directory contains concise reference materials for reviewing the mathematical foundations, neural network concepts, algorithms, architectures, and practical workflows used in **Deep Learning**.

## Topics Covered

### 1. Neural Network Fundamentals
- Artificial neurons and perceptrons
- Weights, biases, and learnable parameters
- Forward propagation
- Activation functions: Sigmoid, Tanh, ReLU, Leaky ReLU, and Softmax
- Loss functions and their purposes

### 2. Training and Optimization
- Backpropagation and gradient computation
- Gradient descent and its variants
- SGD, Momentum, RMSprop, and Adam
- Learning rates and learning-rate scheduling
- Batch size, epochs, and iterations
- Weight initialization

### 3. Mathematical Foundations
- Vectors, matrices, and tensor operations
- Derivatives, partial derivatives, and gradients
- Chain rule and computational graphs
- Common loss-function equations
- Gradient and parameter updates

### 4. Model Generalization
- Overfitting and underfitting
- Bias–variance trade-off
- L1 and L2 regularization
- Dropout and early stopping
- Training, validation, and test sets
- Data leakage and generalization

### 5. Deep Learning Architectures
- Feedforward neural networks (FNNs)
- Convolutional neural networks (CNNs)
- Recurrent neural networks (RNNs)
- Long Short-Term Memory networks (LSTMs)
- Gated Recurrent Units (GRUs)
- Transformers and attention mechanisms
- Autoencoders and generative models

### 6. Practical Frameworks and Workflows
- Tensor operations and automatic differentiation
- Model building and training loops
- Evaluation metrics
- GPU and accelerator basics
- Saving and loading model checkpoints
- Reproducibility and experiment tracking

## Cheat Sheet Guidelines

A useful cheat sheet should include:

- **Concept:** A concise definition.
- **Formula:** The mathematical expression, with variables explained.
- **Purpose:** When and why the technique is used.
- **Example:** A small numerical example or code snippet.
- **Limitations:** Important assumptions or common mistakes.
