# Python Cheat Sheets

This directory contains concise reference materials for reviewing Python syntax, built-in data types, commonly used functions, language features, and programming techniques.

These cheat sheets are designed for quick revision while coding, solving exercises, preparing for examinations, and developing Python projects.

## Cheat Sheet Guidelines

Each cheat sheet should include:

- **Concept:** A clear, concise explanation.
- **Syntax:** Correct Python syntax.
- **Example:** A short, runnable code snippet.
- **Output:** The expected result where useful.
- **Use case:** When and why to use the feature.
- **Common mistakes:** Frequent errors and their solutions.

Prefer examples that demonstrate behavior, not just syntax. Keep beginner-friendly references separate from advanced topics when that improves readability.

## Usage

Use these references during Python practice, assignment preparation, debugging, and project development. Run the examples yourself and consult detailed notes when you need a deeper understanding.

For authoritative information, consult the official [Python documentation](https://docs.python.org/3/).
