## How to Use Cheat Sheets

- Use them for quick revision before assignments, examinations, interviews, and practical work.
- Consult the relevant cheat sheet while coding or solving problems.
- Verify unfamiliar syntax and behavior with official documentation.
- Practice the concepts instead of relying only on memorization.
- Return to detailed notes or books when a topic needs deeper understanding.

## Organization Guidelines

- Place each cheat sheet in the most relevant subject folder.
- Use descriptive filenames, such as `Python-Collections-Cheat-Sheet.md`.
- Prefer concise explanations, readable tables, formulas, and short code examples.
- Include warnings about common mistakes where useful.
- Link to related notebooks, notes, and projects in `AI-ML-Journey`.
- Identify external sources and respect their copyright and licensing terms.

## Recommended File Formats

- **Markdown (`.md`):** editable, searchable, and suitable for GitHub.
- **PDF (`.pdf`):** useful for printing and offline revision.
- **Images (`.png`, `.jpg`, `.svg`):** suitable for visual summaries and diagrams.

Keep Markdown as the preferred format when you want a cheat sheet to be easy to maintain and update.
