# Machine Learning Cheat Sheets

This directory contains concise reference materials for reviewing Machine Learning concepts, algorithms, mathematical formulas, evaluation metrics, and practical modeling workflows.

## Topics Covered

- Supervised, unsupervised, and reinforcement learning
- Classification and regression
- Training, validation, and test datasets
- Features, labels, parameters, and hyperparameters
- Model generalization
- Bias–variance trade-off

### 2. Data Preprocessing
- Handling missing values
- Detecting and treating outliers
- Encoding categorical variables
- Feature scaling and normalization
- Standardization
- Feature engineering and feature selection
- Data leakage prevention

### 3. Supervised Learning Algorithms
- Linear and polynomial regression
- Logistic regression
- k-Nearest Neighbors (KNN)
- Decision trees
- Random forests
- Support Vector Machines (SVM)
- Naive Bayes
- Gradient boosting algorithms

### 4. Unsupervised Learning
- K-means clustering
- Hierarchical clustering
- DBSCAN
- Principal Component Analysis (PCA)
- Dimensionality reduction
- Anomaly detection

### 5. Model Evaluation Metrics

**Regression**
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- \(R^2\) score

**Classification**
- Accuracy
- Precision and recall
- F1-score
- Confusion matrix
- ROC curve and AUC
- Log loss

**Clustering**
- Silhouette score
- Inertia
- Davies–Bouldin index

### 6. Model Selection and Improvement
- Cross-validation
- Hyperparameter tuning
- Grid search and randomized search
- Regularization
- Overfitting and underfitting
- Learning curves
- Class imbalance handling
- Ensemble learning

### 7. Mathematical Foundations
- Linear algebra essentials
- Probability and statistics
- Derivatives and gradients
- Loss and cost functions
- Gradient descent
- Common statistical distributions

### 8. Python ML Libraries
- NumPy for numerical computing
- Pandas for data manipulation
- Matplotlib and Seaborn for visualization
- Scikit-learn for preprocessing, modeling, and evaluation

## Cheat Sheet Guidelines

For each algorithm or technique, include:

- **Definition:** What it is.
- **Intuition:** How it works conceptually.
- **Purpose:** When to use it.
- **Formula:** The relevant equation, with variables explained.
- **Advantages and limitations:** Important trade-offs.
- **Example:** A small numerical example or Python implementation.
- **Evaluation:** How to measure its performance where applicable.

## Usage

Use these references for quick revision, assignments, interviews, and project development. Choose algorithms based on the problem, dataset, assumptions, evaluation criteria, and practical constraints rather than memorizing a universal ranking.

For implementation details, consult the official [scikit-learn documentation](https://scikit-learn.org/stable/).

This directory supports the development of strong Machine Learning foundations within the broader `AI-ML-Journey` repository.
