# 📖 About

**Python Journey from Novice to Expert** is a comprehensive guide that takes readers from Python fundamentals to advanced software engineering concepts, including object-oriented programming, design patterns, concurrency, networking, deployment, and the Python Standard Library.

This document serves as my **reading tracker**, **progress dashboard**, and **learning journal** while studying the book.

> **Note**
>
> I don't create chapter-wise notes.
>
> Instead, every concept is converted into **topic-wise professional Jupyter notebooks** inside the `01-Python/` directory.
