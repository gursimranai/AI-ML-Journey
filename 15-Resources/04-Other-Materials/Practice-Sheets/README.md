The focus is on active practice: applying concepts, solving problems independently, reviewing mistakes, and developing the ability to explain solutions clearly.

## Recommended Organization

Keep existing folders and filenames when they are already clear. For new materials, the following structure is one possible approach:


Organize materials by subject or course when doing so improves navigation. Avoid creating empty folders solely to match this example.

## Organizing Individual Practice Sheets

Use descriptive filenames that identify the topic, assignment, or purpose.

Examples:

```text id="x8q3le"

Partial-Derivatives-Worksheet.pdf
Error-And-Approximation-Questions.pdf
SQL-Joins-Practice.md
Machine-Learning-Metrics-Exercises.pdf
```

Preserve original assignment filenames when they are important for identifying the source or matching course requirements.

For university assignments or multi-part worksheets, consider keeping the original question paper and your own solutions separate:

```text id="v4c2bs"
Example-Assignment/
├── README.md
├── Assignment-Questions.pdf
├── Solutions.md
└── Answer-Key.md
```

This is an illustrative structure. Use only the files that are actually needed.

## Writing Good Solutions

When creating solution files, aim for accuracy, clarity, and reproducibility.

For each problem, include the following where applicable:

1. **Question:** State the problem or identify its source.
2. **Concept:** Explain the principle or formula being used.
3. **Approach:** Describe the reasoning behind the solution.
4. **Working:** Show the steps, calculations, or code.
5. **Final answer:** Clearly identify the result.
6. **Verification:** Check the answer, output, or calculation where possible.
7. **Common mistakes:** Explain important pitfalls when useful.

For programming problems, include readable code and representative test cases. For mathematics, define symbols and show the essential calculation steps rather than providing only the final answer.

## Practice Workflow

A useful approach to working through practice material is:

1. Attempt each problem independently before viewing a solution.
2. Record the concepts that caused difficulty.
3. Check the solution and understand any mistakes.
4. Rework incorrect questions without looking at the answer.
5. Revisit challenging problems after a suitable interval.
6. Add especially useful concepts to your topic notes or cheat sheets.
