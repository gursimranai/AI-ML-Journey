## Recommended Organization

Keep your existing files and filenames when they are already descriptive. If the collection grows, you can organize new materials into subject folders such as:

```text
Reference-Documents/
├── README.md
├── Programming/
├── Mathematics/
├── Data-Science/
├── Machine-Learning/
├── AI-And-LLMs/
└── Development-Tools/
```

Do not create extra folders unless they make the resources easier to find.

## Document Naming

Use names that identify the document's subject and purpose.

Examples:

```text
Python-Installation-Guide.pdf
NumPy-Reference-Notes.pdf
Machine-Learning-Metrics.pdf
Error-And-Approximation-Formulas.pdf
Jupyter-Notebook-Reference.pdf
```

Preserve original filenames when they are meaningful or required to identify the source.

For documents whose purpose is not obvious, include a short description in the relevant README.

## Recording Document Information

For important reference documents, record the following when known:

- **Title:** The document's full title.
- **Source:** The author, organization, course, or publisher.
- **Link:** The original URL or official documentation page.
- **Purpose:** A short explanation of what the document covers.
- **Date or version:** Useful for technical material that changes over time.
- **License:** Relevant copyright or redistribution information.

A small metadata table can help when a folder contains many documents.

| Document | Description | Source |
|---|---|---|
| Example reference | Briefly describe its purpose | Link to the original source |

Replace this illustrative row with real entries only when needed.

## Keeping References Useful

- Prefer official documentation and authoritative sources.
- Check version compatibility before relying on installation instructions or API references.
- Review time-sensitive documents periodically.
- Use descriptive filenames and maintain consistent naming.
- Remove obsolete duplicates when they no longer serve a purpose.
- Link to a canonical source rather than copying a document unnecessarily.
- Keep original source files unchanged when preserving their integrity matters.

## Relationship to Other Repository Sections

Choose the location that best reflects a resource's main purpose.

## Copyright and Attribution

- Do not assume that a publicly accessible document can be redistributed.
- Respect the original author's copyright and licensing conditions.
- Preserve copyright notices and attribution details.
- Share external documents only when permitted.
- Link to the official source when redistribution rights are uncertain.
- Clearly identify your own notes and original work.

The goal is to maintain a trustworthy reference library that supports accurate learning, reproducible development, and efficient problem-solving.
