# Other Learning Materials

This directory contains supplementary learning resources that support the AI-ML-Journey repository, including course notes, lecture notes, practice sheets, reference documents, and tutorials.

These materials complement the main learning paths by providing additional explanations, classroom resources, worked examples, and supporting documentation.

## Contents

### 1. Course Notes

Path: [`Course-Notes/`](Course-Notes/)

Contains notes collected or prepared while studying online courses, university courses, and structured learning programs.

Examples of suitable materials:
- Topic-wise course notes
- Course summaries
- Important concepts and definitions
- Code examples accompanying lessons
- Additional explanations of difficult topics
- Key takeaways from completed lessons

### 2. Lecture Notes

Path: [`Lecture-Notes/`](Lecture-Notes/)

Contains notes related to university lectures, recorded lectures, and individual lessons.

Examples of suitable materials:
- Lecture-wise summaries
- Important definitions and concepts
- Formula explanations
- Worked examples
- Diagrams and lecture references
- Exam preparation notes

### 3. Practice Sheets

Path: [`Practice-Sheets/`](Practice-Sheets/)

Contains worksheets, assignments, and exercises used to strengthen conceptual understanding and problem-solving skills.

Examples of suitable materials:
- Programming exercises
- Mathematics and statistics worksheets
- SQL practice questions
- Machine learning exercises
- Assignment PDFs
- Question banks and answer keys
- Numerical problems with worked solutions

Keep original assignments separate from your own solutions when that distinction is useful.

### 4. Reference Documents

Path: [`Reference-Documents/`](Reference-Documents/)

Contains supplementary documents that are useful for quick reference or deeper study.

Examples of suitable materials:
- PDF notes and technical references
- Official documentation exports, where permitted
- Installation guides
- Technical specifications
- Formula sheets
- Supporting documents for libraries and tools
- Carefully selected reference material from external sources

### 5. Tutorials

Path: [`Tutorials/`](Tutorials/)

Contains step-by-step learning materials that demonstrate how to perform a task or implement a concept.

Examples of suitable materials:
- Python and Jupyter tutorials
- Git and GitHub walkthroughs
- NumPy and Pandas examples
- Development environment setup
- Data preprocessing workflows
- Introductory ML implementation guides
- Tool-specific usage guides

## Choosing the Right Category

| Material | Recommended location |
|---|---|
| Notes from a complete online course | `Course-Notes/` |
| Notes organized by classroom lecture | `Lecture-Notes/` |
| Assignments, worksheets, and question banks | `Practice-Sheets/` |
| Technical PDFs, guides, and reference material | `Reference-Documents/` |
| Step-by-step implementation instructions | `Tutorials/` |

If a resource belongs to a dedicated category elsewhere in `15-Resources/`, such as Books, Cheat Sheets, Interview Questions, Research Papers, or Roadmaps, prefer that category instead of creating unnecessary duplicates.

## Organization Guidelines

- Preserve original filenames when they are already clear and descriptive.
- Use numbered prefixes when they improve ordering.
- Add a short README to a category when it contains enough material to benefit from an index.
- Use descriptive names rather than vague names such as `notes-final-2.pdf`.
- Keep your own explanations and solutions distinguishable from original source material.
- Record the source, author, course, or publication when known.
- Include a brief description for documents whose purpose is not obvious from their filename.
- Avoid storing duplicate copies of the same resource across multiple folders.

## Copyright and Attribution

This directory may contain material from courses, instructors, books, and other educational sources.

- Share externally created material only when redistribution is permitted.
- Preserve author names, source links, copyright notices, and license terms.
- Do not assume that publicly accessible PDFs or course files are free to redistribute.
- Prefer linking to the original source when redistribution rights are unclear.
- Clearly distinguish your original notes and solutions from third-party content.

## Contributing New Materials

Before adding a resource, check whether it already exists in the repository. Place it in the most appropriate category, use a descriptive filename, and update the relevant README when necessary.

The goal is to maintain a useful, organized learning library that complements the main AI-ML-Journey learning path without replacing topic-specific notes, code examples, or projects.
