# Course Notes

This directory contains notes and supplementary learning materials created while studying online courses, university subjects, and structured technical learning programs.

The notes are intended to reinforce understanding, summarize important concepts, and provide a convenient reference when revisiting topics.

## Scope

Course notes may cover the following areas:

### Programming Fundamentals
- Python, C, and C++
- Programming logic and control flow
- Functions and object-oriented programming
- Data structures and algorithms
- Problem-solving techniques

### Mathematics and Statistics
- Linear algebra
- Calculus
- Probability and statistics
- Discrete mathematics
- Optimization fundamentals
- Numerical methods

### Data Science and Machine Learning
- Data cleaning and preprocessing
- Exploratory data analysis
- Feature engineering
- Supervised and unsupervised learning
- Model evaluation and validation
- Statistical learning concepts

### Deep Learning and AI
- Neural networks and backpropagation
- Convolutional neural networks
- Sequence models and attention
- Transformers and large language models
- Generative AI fundamentals
- Model training and inference

### Development Tools and Engineering
- Git and GitHub
- Python environments and package management
- Jupyter Notebook
- VS Code
- APIs and software development practices
- Reproducible experiments

These are suggested subject areas, not a requirement to create every category.

## Recommended Organization

Keep existing files and folder names where they are already clear. For new materials, use a consistent structure such as:

```text
Course-Notes/
├── README.md
├── Python/
├── Mathematics/
├── Data-Science/
├── Machine-Learning/
├── Deep-Learning/
└── Development-Tools/
```

Use subject folders only when they help organize the actual resources in your collection.

For each course, you may keep the following information alongside its notes:

- Course or subject name
- Instructor or provider, if known
- Original course URL
- Topics covered
- Related files and notebooks
- Source and license information

## Writing Effective Course Notes

A useful set of notes should prioritize understanding over copying entire lessons.

Where appropriate, include:

1. **Concept:** A clear explanation of the topic.
2. **Terminology:** Important definitions and distinctions.
3. **Examples:** Short, correct examples that demonstrate the concept.
4. **Code:** Runnable code with meaningful comments when applicable.
5. **Visuals:** Diagrams, tables, or plots that clarify difficult ideas.
6. **Applications:** Examples of where the concept is useful.
7. **Common mistakes:** Errors, misconceptions, and edge cases.
8. **References:** Links to official documentation or original course material.

Not every topic requires every section. Keep the notes proportionate to the complexity of the material.

## File Naming

Prefer descriptive names that identify the course or subject.

Examples:

```text
Python-Functions.md
Linear-Algebra-Notes.md
Machine-Learning-Fundamentals.md
Data-Preprocessing-Notes.md
```

For lecture-by-lecture material, use the `Lecture-Notes/` directory instead when that organization is more appropriate.

- Use `02-Cheat-Sheets/` for concise summaries intended for quick revision.
- Use `03-Interview-Questions/` for interview-focused questions and answers.
- Use `04-Other-Materials/Practice-Sheets/` for assignments and exercises.
- Use `04-Other-Materials/Reference-Documents/` for supporting technical documents.
- Use `04-Other-Materials/Tutorials/` for step-by-step guides.

Avoid maintaining duplicate copies when a relative link to the original resource is sufficient.

## Copyright and Attribution

- Respect the course provider's terms and the original author's copyright.
- Do not redistribute paid course materials unless redistribution is permitted.
- Prefer original explanations written in your own words.
- Attribute external diagrams, quotations, and code when required.
- Link to the original course or documentation where possible.

The goal is to build a reliable collection of understandable, reusable notes that supports long-term learning and practical application.
