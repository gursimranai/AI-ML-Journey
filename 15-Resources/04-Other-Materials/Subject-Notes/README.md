# Subject Notes

This directory contains subject-specific notes that support the study of programming, mathematics, data science, artificial intelligence, and machine learning.

The notes are organized by subject to make concepts easier to locate, revise, and reference throughout the AI/ML learning journey.

## Organization

Arrange notes into subject-specific folders as the collection grows.

```text
Subject-Notes/
├── README.md
├── NumPy/
├── Python/
├── Mathematics/
├── Data-Science/
└── Machine-Learning/
```

## Types of Materials

- **Concept Notes:** Definitions, explanations, and theoretical foundations.
- **Technical Notes:** Syntax, functions, APIs, and implementation details.
- **Reference Notes:** Important formulas, summaries, and quick revision material.
- **PDF Notes:** Downloaded or personally prepared subject-specific documents.

## Usage

- Keep each file in the folder corresponding to its primary subject.
- Use descriptive filenames that identify the topic.
- Preserve the original source or author attribution for external materials.
- Prefer detailed explanations here and short summaries in the Cheat Sheets directory.
