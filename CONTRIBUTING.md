# Contributing to AI-ML-Journey

Thank you for your interest in contributing to **AI-ML-Journey**!

This repository documents a learning journey across Python, Mathematics, Data Science, Machine Learning, Deep Learning, Generative AI, DSA, and related technologies.

Contributions that improve accuracy, clarity, code quality, and learning value are welcome.

## Ways to Contribute

- Fix errors in notes, formulas, explanations, or code.
- Improve beginner-friendly explanations.
- Add useful examples and practice problems.
- Improve Jupyter notebooks and visualizations.
- Add projects, exercises, and learning resources.
- Fix broken links and documentation issues.

## Contribution Guidelines

1. Check the existing folder structure before adding new files.
2. Follow the existing naming conventions and use kebab-case for new folder and file names where practical.
3. Keep explanations clear, accurate, and beginner-friendly.
4. Include comments in code when they help explain important concepts.
5. Test code examples before submitting them.
6. Avoid committing virtual environments, generated files, large datasets, credentials, or API keys.
7. Use reliable sources when adding technical explanations.
8. Do not claim that code, projects, or topics are complete unless they have been verified.

## Working on a Contribution

1. Fork the repository.
2. Clone your fork locally.
3. Create a branch for your changes.
4. Make and test your changes.
5. Commit with a clear message.
6. Push the branch to your fork.
7. Open a pull request explaining what you changed and why.

## Suggested Commit Messages

- `docs: improve Python strings notes`
- `fix: correct derivative formula`
- `feat: add binary search examples`
- `test: add practice cases for arrays`

## Pull Requests

Please keep pull requests focused and include:

- A clear description of the changes.
- The reason the changes are useful.
- Testing performed, where applicable.
- Screenshots for meaningful visual changes, if helpful.

Thank you for helping make AI-ML-Journey more useful for learners!
