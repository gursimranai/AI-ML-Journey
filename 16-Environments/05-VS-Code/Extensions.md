# Useful VS Code Extensions

Extensions add languages, tools, and development features to VS Code.

Install extensions from the Extensions view using `Ctrl + Shift + X`.

## 1. Essential Extensions

| Extension | Publisher | Purpose |
|---|---|---|
| Python | Microsoft | Python language support, execution, and debugging integration |
| Pylance | Microsoft | Python IntelliSense, type checking, and code navigation |
| Jupyter | Microsoft | Work with `.ipynb` notebooks |
| Ruff | Astral Software | Python linting and code formatting |
| GitLens | GitKraken | Additional Git history and code insights |

Extension availability and features can change, so verify the publisher and current documentation before installing.

## 2. Python

The Python extension provides Python-specific development features, including interpreter selection and debugging integration.

Install it if you plan to write Python programs in VS Code.

Official page: [Python Extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python)

## 3. Pylance

Pylance provides code completion, navigation, type information, and other Python language features.

It is commonly used alongside the Python extension.

Official page: [Pylance](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-pylance)

## 4. Jupyter

The Jupyter extension supports notebook workflows inside VS Code.

It helps you open `.ipynb` files, execute cells, select kernels, and inspect outputs.

Official page: [Jupyter Extension](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter)

## 5. Ruff

Ruff can identify common Python code issues and format Python code.

It is useful for maintaining consistent code quality as projects grow.

Official page: [Ruff Extension](https://marketplace.visualstudio.com/items?itemName=charliermarsh.ruff)

## 6. GitLens

GitLens adds features for exploring Git history, authorship, and repository changes.

VS Code already includes built-in Git integration, so GitLens is optional.

Official page: [GitLens](https://marketplace.visualstudio.com/items?itemName=eamodio.gitlens)

## 7. Install an Extension

1. Open VS Code.
2. Press `Ctrl + Shift + X`.
3. Search for the extension by name.
4. Verify its publisher.
5. Select **Install**.
6. Follow any prompts to reload VS Code.

## 8. Recommended Setup for AI/ML Learning

Start with:

1. Python
2. Pylance
3. Jupyter

Add Ruff or GitLens when you need their features.

You do not need dozens of extensions to become productive. Too many extensions can increase resource usage and introduce unnecessary complexity.
