# Visual Studio Code (VS Code)

Visual Studio Code is a lightweight, extensible code editor used to write, run, debug, and manage software projects.

It is especially useful for Python development, Data Science, Machine Learning, Git, Jupyter notebooks, and general software engineering.

## 🧠 Why Use VS Code?

- Write and organize code across multiple files.
- Use extensions to add language and development features.
- Run and debug Python programs.
- Work with virtual environments and Conda environments.
- Open and execute Jupyter notebooks.
- Track code changes using Git.
- Manage projects through an integrated terminal.

## 🚀 Recommended Setup for Python

1. Install Python.
2. Install VS Code.
3. Install the Microsoft Python extension.
4. Open your project folder.
5. Create or activate a virtual environment.
6. Select the correct Python interpreter.
7. Run a test program.
8. Configure Jupyter and Git when needed.

## ⌨️ Useful Keyboard Shortcuts

| Shortcut (Windows) | Action |
|---|---|
| `Ctrl + Shift + P` | Open the Command Palette |
| `Ctrl + `` ` | Toggle the integrated terminal |
| `Ctrl + P` | Open a file by name |
| `Ctrl + Shift + E` | Open Explorer |
| `Ctrl + Shift + G` | Open Source Control |
| `F5` | Start or continue debugging |
| `Shift + F5` | Stop debugging |
| `Ctrl + /` | Toggle line comments in supported languages |

Keyboard shortcuts can vary by operating system and keymap.

## 💡 Best Practices

- Open the project root rather than an isolated source file.
- Use a project-specific environment.
- Select and verify the intended Python interpreter.
- Install only the extensions you need.
- Use Git for version control.
- Keep credentials and local environment folders out of Git.
- Format and test code before committing changes.
