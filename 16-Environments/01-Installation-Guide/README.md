# Installation Guide

This section explains how to set up a development environment for Python programming, AI/ML learning, and Git-based project development.

## 📂 Contents

| File | Description |
|---|---|
| `Windows-Setup.md` | Prepare Windows for programming and development |
| `Python-Installation.md` | Install Python and verify the installation |
| `Git-And-GitHub-Setup.md` | Configure Git and connect your projects to GitHub |
| `Troubleshooting.md` | Resolve common setup and installation issues |

## 🎯 Recommended Setup Order

1. Configure Windows for development.
2. Install Python and verify that it works.
3. Install and configure Git.
4. Create a project folder and verify your tools.
5. Review troubleshooting steps if something fails.

## 🛠️ Recommended Tools

- **Python:** Python programming language
- **Visual Studio Code:** Code editor
- **Git:** Version control system
- **GitHub:** Online repository hosting
- **Windows Terminal or PowerShell:** Command-line tools

## 💡 Important Notes

- Use official download sources whenever possible.
- Keep Python, Git, and development tools updated.
- Verify each installation before moving to the next step.
- Use virtual environments to isolate project dependencies.
- Avoid committing passwords, API keys, tokens, or other secrets to GitHub.

This guide is intended to help learners establish a reliable development environment before progressing to Python, data science, and AI/ML.
