# Examples — AI and Machine Learning for Coders

This directory contains standalone Python scripts and practical experiments related to *AI and Machine Learning for Coders* by Laurence Moroney.

Most learning notes and code implementations are documented together in Jupyter Notebooks under the `Notes/` directory.

## Purpose

- Store standalone Python implementations.
- Experiment with concepts from the book.
- Keep reusable code separate from notebook-based learning.
- Practice applying AI and ML techniques.

## Contents

Examples are added as needed while studying the book. This directory may remain empty when an implementation is already sufficiently documented in a notebook.
