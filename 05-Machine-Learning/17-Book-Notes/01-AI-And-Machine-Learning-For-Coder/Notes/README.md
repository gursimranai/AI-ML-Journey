# Notes — AI and Machine Learning for Coders

This directory contains Jupyter Notebooks documenting my learning from *AI and Machine Learning for Coders* by Laurence Moroney.

The notebooks combine theoretical explanations and practical Python implementations in a single place.

## Documentation Approach

Each notebook uses:

- **Markdown cells:** Concepts, explanations, important points, and observations.
- **Code cells:** Python implementations, experiments, and examples.
- **Output cells:** Execution results and visualizations.

## Notebook Contents

Notebooks are created progressively based on the topics studied from the book. Each notebook may cover one or multiple related topics.

## Purpose

- Build a clear understanding of AI and ML concepts.
- Practice implementations using Python and relevant libraries.
- Maintain a record of experiments and learning progress.
- Create useful revision material for future reference.
