# Examples — Machine Learning with Python Cookbook

This directory contains standalone Python scripts and practical implementations based on techniques covered in *Machine Learning with Python Cookbook*, published by O'Reilly.

The primary notes and code implementations are maintained together in Jupyter Notebooks under the `Notes/` directory.

## Purpose

- Implement practical machine learning recipes.
- Experiment with Python libraries and techniques.
- Build reusable code examples.
- Explore alternative approaches to solving ML problems.

## Contents

Standalone scripts and experiments are added whenever they provide value beyond the notebook implementations.

Code already documented in Jupyter Notebooks does not need to be duplicated here.
