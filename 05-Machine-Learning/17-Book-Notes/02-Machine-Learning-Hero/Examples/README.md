# Examples — Machine Learning Hero

This directory contains standalone Python scripts, implementations, and practical experiments related to *Machine Learning Hero*.

The primary learning notes and code implementations are maintained together in Jupyter Notebooks under the `Notes/` directory.

## Purpose

- Store standalone Python implementations.
- Practice machine learning concepts through code.
- Experiment with different algorithms and techniques.
- Keep reusable code separate from notebook-based learning.

## Contents

Examples are added whenever a standalone implementation is useful. Code already documented in Jupyter Notebooks does not need to be duplicated here.
