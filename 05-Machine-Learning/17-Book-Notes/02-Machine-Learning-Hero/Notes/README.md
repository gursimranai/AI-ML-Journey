# Notes — Machine Learning Hero

This directory contains Jupyter Notebooks documenting concepts, explanations, code implementations, and experiments while studying *Machine Learning Hero*.

## Documentation Approach

Learning materials are documented directly in Jupyter Notebooks using:

- **Markdown cells:** Concepts, explanations, definitions, and important observations.
- **Code cells:** Python implementations, practical examples, and experiments.
- **Output cells:** Results, visualizations, and execution outputs.

## Notebook Organization

Notebooks are created progressively according to the topics studied. Each notebook may cover one or multiple related concepts.

## Learning Objectives

- Strengthen machine learning fundamentals.
- Understand practical ML techniques and workflows.
- Implement concepts using Python.
- Experiment with different approaches and techniques.
- Maintain useful revision material.
