# Examples — AI and Machine Learning Action

This directory contains standalone Python scripts, code implementations, and practical experiments related to the concepts studied in *AI and Machine Learning Action* by Aniket Jain.

The primary learning notes and code implementations are maintained together in Jupyter Notebooks under the `Notes/` directory.

## Purpose

- Practice AI and machine learning concepts through code.
- Implement techniques covered in the learning material.
- Experiment with Python libraries and different approaches.
- Maintain reusable standalone implementations.

## Contents

Examples are added progressively whenever a standalone implementation is useful.

Code already documented in Jupyter Notebooks does not need to be duplicated here.
