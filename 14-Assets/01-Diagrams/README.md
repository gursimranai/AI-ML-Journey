# 📊 Diagrams

This directory contains conceptual diagrams that explain programming concepts, technical relationships, system components, and foundational AI/ML ideas visually.

Diagrams help simplify complex topics, improve conceptual understanding, and make learning notes and documentation easier to follow.

## 📂 Contents

| Asset | Description |
|---|---|
| `Core-Data-Types.png` | Visual reference for Python's core data types. |
| `Different-Approaches.png` | Illustrates different approaches to a concept or problem. |
| `Python-Role-In-ML.png` | Explains the role of Python in machine learning. |
| `Python-Strength.png` | Highlights Python's strengths and capabilities. |
| `Types-Of-AI.png` | Illustrates categories or types of artificial intelligence. |

*The descriptions above are based on the filenames. Update them if the actual images cover different topics.*

## 🎯 Purpose

- Explain concepts that are difficult to understand through text alone.
- Illustrate relationships between concepts and components.
- Support Python, mathematics, data science, and AI/ML learning materials.
- Provide reusable visuals for notebooks, READMEs, tutorials, and project documentation.

## 🗂️ What Belongs Here?

Use this folder for:

- Conceptual diagrams and educational illustrations.
- Diagrams showing relationships, categories, or hierarchies.
- Technical concept maps.
- High-level architecture diagrams that are not primarily step-by-step workflows.

Use other asset categories for dedicated flowcharts, mathematical plots, data visualizations, and subject-specific visual collections when those categories are a better fit.

## 📝 Naming Guidelines

Use descriptive filenames in kebab-case:

- `Core-Data-Types.png`
- `Types-Of-AI.png`
- `Python-Role-In-ML.png`

Prefer meaningful names over generic filenames such as `image1.png` or `diagram-final.png`.

## 🔗 Using Diagrams in Markdown

Reference diagrams from other files using relative paths.

For example, from `01-Python/01-Fundamentals/01-Notebooks/`:

```markdown
![Python Core Data Types](../../../14-Assets/01-Diagrams/Core-Data-Types.png)
```

Check the relative path whenever the image or referencing file is moved.

## ✅ Best Practices

- Keep diagrams readable and well-organized.
- Prefer clear labels and consistent terminology.
- Preserve attribution and comply with the original asset's license when using third-party visuals.
- Avoid unnecessary duplicate copies.
- Update this README when adding or removing important assets.
