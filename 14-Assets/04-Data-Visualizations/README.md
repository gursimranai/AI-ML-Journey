# 📊 Data Visualizations

This directory contains visual resources used to understand, explore, analyze, and communicate data. These visuals help reveal patterns, relationships, distributions, anomalies, and trends in datasets.

They support exploratory data analysis (EDA), data cleaning, statistics, and data science workflows.

## 🎯 Purpose

- Understand datasets through visual exploration.
- Identify patterns, trends, and relationships between variables.
- Detect outliers, missing values, and potential data-quality issues.
- Explain statistical findings visually.
- Support data analysis and preprocessing lessons.
- Communicate insights clearly in notebooks and documentation.

## 🗂️ What Belongs Here?

Use this folder for:

- **Exploratory Data Analysis:** visual summaries and analytical plots.
- **Distributions:** histograms, density plots, and distribution comparisons.
- **Relationships:** scatter plots, correlation heatmaps, and pair plots.
- **Categorical Analysis:** bar charts and category comparisons.
- **Data Quality:** visual explanations of missing values and duplicate records.
- **Outlier Analysis:** box plots and other visual methods for identifying unusual observations.
- **Data Cleaning:** illustrations explaining data-quality problems and their effects.

## 📝 Naming Guidelines

Use descriptive filenames in kebab-case.

Examples:

- `Outlier-Understanding.png`
- `Duplicate-Records-Root-Cause-Analysis.png`
- `Data-Cleaning-Challenges.png`
- `Correlation-Heatmap.png`
- `Missing-Values-Analysis.png`
- `Feature-Distribution-Comparison.png`

Choose filenames that accurately describe the content.

## 🔗 Using Visualizations in Markdown

Reference an image from a notebook or README using a relative path.

For example, from `01-Python/01-Fundamentals/01-Notebooks/`:

```markdown
![Outlier Understanding](../../../14-Assets/04-Data-Visualizations/Outlier-Understanding.png)
```

Adjust the relative path when referencing the image from a different location.

## ✅ Best Practices

- Use appropriate chart types for the data and analytical question.
- Label axes and provide titles where needed.
- Keep legends and annotations clear.
- Avoid misleading scales and unnecessary visual effects.
- Ensure that visualizations accurately represent the underlying data.
- Preserve attribution and follow licensing requirements for external assets.
- Update this README when important assets are added or removed.

---

**Goal:** Make data patterns, statistical findings, and data-quality issues easier to understand through clear and accurate visualizations.
