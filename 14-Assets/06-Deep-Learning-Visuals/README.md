# 🧠 Deep Learning Visuals

This directory contains visual resources that explain deep learning concepts, neural network architectures, training processes, and advanced learning techniques.

These visuals support the study of artificial neural networks, backpropagation, activation functions, convolutional neural networks, recurrent neural networks, transformers, and other deep learning architectures.

## 🎯 Purpose

- Develop visual intuition for neural networks and deep learning.
- Understand how neural network layers process information.
- Illustrate forward propagation and backpropagation.
- Explain activation functions, loss functions, and optimization.
- Visualize common deep learning architectures.
- Support deep learning notebooks, notes, tutorials, and project documentation.

## 🗂️ What Belongs Here?

Use this folder for:

- **Neural Network Fundamentals:** neurons, layers, weights, biases, and connections.
- **Activation Functions:** ReLU, sigmoid, tanh, softmax, and their graphs.
- **Training Processes:** forward propagation, backpropagation, and gradient updates.
- **Loss Functions:** visual explanations of common loss functions.
- **Convolutional Neural Networks (CNNs):** convolution, pooling, filters, and feature maps.
- **Recurrent Neural Networks (RNNs):** sequential processing, hidden states, and recurrent connections.
- **Transformers:** attention mechanisms, encoder-decoder structures, and transformer blocks.
- **Optimization:** learning rates, gradient descent, and training behavior.

## 📝 Naming Guidelines

Use descriptive filenames in kebab-case.

Examples:

- `Neural-Network-Architecture.png`
- `Forward-And-Backward-Propagation.png`
- `Activation-Functions-Comparison.png`
- `CNN-Architecture.png`
- `RNN-Architecture.png`
- `Transformer-Architecture.png`
- `Self-Attention-Mechanism.png`

Choose filenames that accurately describe the visual content.

## 🔗 Using Visuals in Markdown

Reference images from notebooks or documentation using relative paths.

For example, from `01-Python/01-Fundamentals/01-Notebooks/`:

```markdown
![Neural Network Architecture](../../../14-Assets/06-Deep-Learning-Visuals/Neural-Network-Architecture.png)
```

Adjust the relative path according to the location of the file that references the image.

## ✅ Best Practices

- Label layers, connections, tensors, and mathematical operations clearly.
- Distinguish training-time operations from inference-time operations where relevant.
- Use accurate terminology for architectures and components.
- Keep diagrams readable and avoid unnecessary complexity.
- Include mathematical notation where it improves understanding.
- Preserve attribution and follow licensing requirements for third-party visuals.
- Update this README when important visuals are added or removed.
