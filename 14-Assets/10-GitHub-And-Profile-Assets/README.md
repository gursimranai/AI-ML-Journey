# 🐙 GitHub and Profile Assets

This folder contains visual assets used to customize, document, and improve the presentation of GitHub profiles and developer portfolios associated with the AI-ML-Journey repository.

These assets help maintain a consistent and professional identity across GitHub, project documentation, and developer profiles.

## 🎯 Purpose

GitHub and profile assets can be used to:

- Customize a GitHub profile README.
- Create GitHub profile banners and headers.
- Display technology stacks and skill badges.
- Showcase contribution statistics and activity cards.
- Improve repository presentation.
- Support a consistent developer portfolio.

## 📂 Types of Assets

### 1. GitHub Profile Graphics

- Profile banners and headers
- Profile README illustrations
- Contribution and activity graphics
- Profile section decorations

### 2. Technology and Skill Badges

- Programming language badges
- AI and machine learning technology badges
- Development tool badges
- Framework and library badges

### 3. Portfolio and Personal Branding

- Developer portfolio graphics
- Profile thumbnails
- Professional background images
- Supporting visuals for developer profiles

## 🏷️ Naming Convention

Use descriptive filenames in **kebab-case**.

Examples:

- `github-profile-banner.png`
- `github-profile-header.svg`
- `technology-stack.png`
- `contribution-graph-preview.png`
- `portfolio-preview.png`
- `profile-readme-illustration.svg`

Use PNG or WebP for raster graphics and SVG for scalable vector graphics when appropriate.

## 🔗 Referencing Assets

Use relative paths when referencing local assets from repository Markdown files.

Example from the repository root:

```markdown
![GitHub profile banner](14-Assets/10-GitHub-And-Profile-Assets/github-profile-banner.png)
```

For a GitHub profile README hosted in a separate repository, use a suitable public raw-file URL or another publicly accessible image URL. A relative path inside this repository will not automatically resolve from an unrelated repository.

## 📝 Attribution and Licensing

- Follow the license of any downloaded graphics or templates.
- Credit original creators when required.
- Do not use copyrighted graphics without permission.
- Avoid including private information in public profile assets.
- Review badges and statistics before presenting them as evidence of skills or achievements.
