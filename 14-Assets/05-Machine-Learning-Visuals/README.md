# 🤖 Machine Learning Visuals

This directory contains visual resources that explain machine learning concepts, algorithms, model architectures, training processes, and evaluation techniques.

These visuals support the study of supervised learning, unsupervised learning, model optimization, feature engineering, and model evaluation.

## 🎯 Purpose

- Build visual intuition for machine learning concepts.
- Understand how algorithms learn patterns from data.
- Illustrate model training, prediction, and evaluation workflows.
- Explain relationships between features, targets, predictions, and errors.
- Support machine learning notes, notebooks, tutorials, and project documentation.

## 🗂️ What Belongs Here?

Use this folder for:

- **Machine Learning Fundamentals:** terminology, learning paradigms, and common workflows.
- **Supervised Learning:** regression, classification, and prediction concepts.
- **Unsupervised Learning:** clustering, dimensionality reduction, and pattern discovery.
- **Model Training:** training-validation-test splits and learning processes.
- **Model Evaluation:** confusion matrices, ROC curves, precision-recall curves, and evaluation metrics.
- **Feature Engineering:** feature selection, encoding, scaling, and transformation concepts.
- **Optimization:** model loss, parameter updates, and learning behavior.
- **Ensemble Learning:** visual explanations of bagging, boosting, and model combinations.

## 📝 Naming Guidelines

Use descriptive filenames in kebab-case.

Examples:

- `Machine-Learning-Terminology.png`
- `Supervised-Vs-Unsupervised-Learning.png`
- `Train-Validation-Test-Split.png`
- `Confusion-Matrix.png`
- `Bias-Variance-Tradeoff.png`
- `Gradient-Descent-For-Model-Training.png`

Use filenames that accurately describe each visual.

## 🔗 Using Visuals in Markdown

Reference images from notebooks or documentation using relative paths.

For example, from `01-Python/01-Fundamentals/01-Notebooks/`:

```markdown
![Machine Learning Terminology](../../../14-Assets/05-Machine-Learning-Visuals/Machine-Learning-Terminology.png)
```

Adjust the path to match the location of the file that references the image.

## ✅ Best Practices

- Use accurate terminology and clearly labeled diagrams.
- Distinguish training data, validation data, and test data correctly.
- Label axes and metrics when presenting charts.
- Avoid diagrams that imply an algorithm works differently from its actual behavior.
- Prefer readable, educational visuals over decorative graphics.
- Preserve attribution and follow licensing requirements for external assets.
- Update this README when important visuals are added or removed.
