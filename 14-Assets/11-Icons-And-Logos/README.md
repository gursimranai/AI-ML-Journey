# 🎨 Icons and Logos

This folder contains icons, logos, and graphical assets used throughout the **AI-ML-Journey** repository and its related projects.

These assets help improve documentation, identify technologies, and maintain a consistent visual style across notes, notebooks, project READMEs, and diagrams.

## 🎯 Purpose

Use this folder to organize visual assets for:

- Programming languages
- Python libraries and data science tools
- Machine learning and deep learning frameworks
- AI and generative AI technologies
- Development tools and platforms
- Open-source projects and custom branding

## 📚 Asset Categories

### 1. Programming Languages

Examples include Python, C, C++, JavaScript, and SQL logos.

### 2. Libraries and Frameworks

Examples include NumPy, Pandas, Matplotlib, Scikit-learn, PyTorch, and TensorFlow.

### 3. AI and Machine Learning

Icons representing machine learning, neural networks, NLP, computer vision, LLMs, and generative AI.

### 4. Development Tools

Icons for Git, GitHub, VS Code, Jupyter, Linux, and other development tools.

### 5. Project Logos

Custom logos and icons created for projects within the AI-ML-Journey ecosystem.

## 🗂️ Organization Guidelines

As the collection grows, assets can be grouped into subfolders:

```text
11-Icons-And-Logos/
├── README.md
├── Programming-Languages/
├── Libraries-And-Frameworks/
├── AI-And-ML/
├── Development-Tools/
└── Project-Logos/
```

These subfolders are optional. Create them only when they make the collection easier to navigate.

## 🏷️ Naming Convention

Use descriptive filenames in **kebab-case**.

Examples:

- `python-logo.svg`
- `numpy-logo.svg`
- `pandas-logo.svg`
- `scikit-learn-logo.svg`
- `pytorch-logo.svg`
- `tensorflow-logo.svg`
- `github-logo.svg`
- `project-logo.png`

Prefer SVG for scalable vector graphics. Use PNG or WebP when raster images are more appropriate.

## 🔗 Using Icons and Logos

Reference an asset from the repository root using a relative path:

```markdown
![Python logo](14-Assets/11-Icons-And-Logos/python-logo.svg)
```

Adjust the path based on the location of the Markdown file that uses the asset.

## 📝 Attribution and Licensing

- Prefer official logos and authorized asset sources.
- Check the license and terms of use before redistributing assets.
- Provide attribution when required.
- Follow applicable brand guidelines.
- Do not imply endorsement by a company or organization without authorization.

## 💡 Best Practices

- Keep filenames descriptive and consistent.
- Avoid unnecessary duplicate assets.
- Use transparent backgrounds where suitable.
- Maintain appropriate image quality and file sizes.
- Use icons to clarify information rather than decorate every section.
- Ensure that project logos accurately represent the associated projects.
