# 👁️ Computer Vision Visuals

This folder contains visual learning resources for **Computer Vision (CV)**, including image processing, feature extraction, deep learning architectures, and vision-based AI applications.

The visuals are designed to simplify complex concepts and support the explanations, code examples, and projects in the AI-ML-Journey repository.

## 🎯 Purpose

Computer Vision enables machines to extract meaningful information from images and videos. Visual explanations help illustrate how images are represented, processed, analyzed, and interpreted by computer vision systems.

## 📚 Topics Covered

### 1. Image Fundamentals

- Pixels, channels, and image dimensions
- RGB, grayscale, and other color spaces
- Image resolution and aspect ratio
- Image formats and compression
- Image representation as numerical arrays
- Image loading and preprocessing

### 2. Image Processing

- Image resizing and cropping
- Image normalization
- Image filtering and blurring
- Edge detection
- Thresholding and segmentation
- Morphological operations
- Color space conversion
- Noise reduction

### 3. Feature Extraction

- Edges, corners, and keypoints
- Image gradients
- Histograms of oriented gradients (HOG)
- Local feature descriptors
- Traditional computer vision pipelines

### 4. Deep Learning for Computer Vision

- Convolutional Neural Networks (CNNs)
- Convolution and feature maps
- Filters and kernels
- Stride and padding
- Pooling layers
- Feature hierarchies
- Transfer learning
- Vision Transformers (ViTs)

### 5. Core Computer Vision Tasks

- Image classification
- Object detection
- Image segmentation
- Object tracking
- Face detection
- Pose estimation
- Optical character recognition (OCR)
- Image similarity and retrieval

### 6. Modern Vision Applications

- Real-time object detection
- Medical and scientific image analysis
- Autonomous systems
- Visual search
- Image captioning
- Multimodal vision-language models
- Video understanding

## 🗂️ Organization Guidelines

- Store image-processing and computer-vision concept diagrams here.
- Use this folder for CNN, object detection, segmentation, and vision-model illustrations.
- Store general deep learning visuals in `../06-Deep-Learning-Visuals/` when they are not specifically vision-focused.
- Store general-purpose process diagrams in `../02-Flowcharts/`.
- Store plots and statistical visualizations in `../04-Data-Visualizations/` when they primarily represent data rather than vision concepts.

## 🖼️ Naming Convention

Use descriptive filenames in **kebab-case**.

Examples:

- `image-representation-explained.png`
- `rgb-vs-grayscale.png`
- `image-preprocessing-pipeline.png`
- `convolution-operation.png`
- `cnn-architecture.png`
- `object-detection-explained.png`
- `image-segmentation.png`
- `vision-transformer-architecture.png`

Prefer `.png`, `.svg`, or `.webp`, depending on the visual's purpose.

## 🔗 Using Visuals in Markdown

Reference an image using a relative path:

```markdown
![CNN architecture](../../14-Assets/08-Computer-Vision-Visuals/cnn-architecture.png)
```

Adjust the relative path based on the location of the Markdown file that references the image.
