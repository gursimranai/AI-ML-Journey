# 🧠 NLP and LLM Visuals

This folder contains visual learning resources for **Natural Language Processing (NLP), Large Language Models (LLMs), and language-based AI systems**.

The visuals are intended to make complex concepts easier to understand, revise, and explain through diagrams, illustrations, and conceptual representations.

## 🎯 Purpose

NLP and LLM visuals help explain how machines process human language, represent text numerically, learn contextual relationships, and generate responses.

## 📚 Topics Covered

### 1. Natural Language Processing (NLP)

- NLP fundamentals and common applications
- Text preprocessing and normalization
- Tokenization and text segmentation
- Stop-word removal and stemming
- Lemmatization
- Part-of-speech tagging
- Named Entity Recognition (NER)
- Sentiment analysis
- Text classification

### 2. Text Representation and Embeddings

- Bag of Words (BoW)
- N-grams
- Term Frequency–Inverse Document Frequency (TF-IDF)
- Word embeddings
- Semantic similarity
- Vector representations of text
- Sentence and document embeddings

### 3. Transformers and Attention

- Transformer architecture
- Encoder and decoder structures
- Self-attention
- Multi-head attention
- Positional encoding
- Query, Key, and Value
- Contextual representations
- Attention masks

### 4. Large Language Models (LLMs)

- LLM fundamentals
- Pre-training and fine-tuning
- Next-token prediction
- Tokenization in language models
- Context windows
- Prompt engineering concepts
- Inference and text generation
- Model parameters and temperature

### 5. Modern LLM Applications

- Retrieval-Augmented Generation (RAG)
- Embedding-based retrieval
- Vector databases
- Semantic search
- AI agents and tool calling
- LLM application pipelines
- Evaluation and hallucination concepts

## 🗂️ Organization Guidelines

- Store NLP and language-processing concept diagrams in this folder.
- Use this folder for transformer, attention, embedding, and LLM architecture visuals.
- Keep general-purpose flowcharts in `../02-Flowcharts/`.
- Store general machine learning diagrams in `../05-Machine-Learning-Visuals/`.
- Store deep learning architecture visuals that are not specifically NLP-focused in `../06-Deep-Learning-Visuals/`.

## 🖼️ Naming Convention

Use descriptive, readable filenames in **kebab-case**.

Examples:

- `text-preprocessing-pipeline.png`
- `tokenization-explained.png`
- `word-embeddings.png`
- `self-attention-mechanism.png`
- `transformer-architecture.png`
- `llm-text-generation.png`
- `rag-pipeline.png`

Prefer `.png`, `.svg`, or `.webp`, depending on the image type and quality requirements.

## 🔗 Using Visuals in Markdown

Reference an image from a Markdown file using a relative path.

```markdown
![Transformer architecture](../../14-Assets/07-NLP-And-LLM-Visuals/transformer-architecture.png)
```

Adjust the relative path according to the location of the Markdown file that uses the image.

## 📝 Attribution and Licensing

- Add attribution when an image is sourced from an external creator or website and attribution is required.
- Follow the original license when reusing or modifying external visuals.
- Clearly distinguish original diagrams from externally sourced material.
- Avoid presenting generated or illustrative diagrams as exact representations of a model's internal implementation.

## 💡 Best Practices

- Prefer clear labels, readable text, and uncluttered layouts.
- Use consistent terminology and notation.
- Ensure that each visual communicates one main concept.
- Keep visuals aligned with the accompanying notes and code examples.
- Update visuals when the associated learning material changes.
