# 📘 Python Fundamentals — Notebooks

This folder contains Jupyter Notebooks for learning Python fundamentals step by step, from writing your first Python program to working with operators, input/output, and conditional statements.

Each notebook focuses on a specific concept and includes explanations, code examples, and practical demonstrations.

## 📂 Notebook Structure

| No. | Notebook | Topics Covered |
|---|---|---|
| 01 | `01-Introduction-To-Python.ipynb` | What Python is, its applications, features, and why it is used in programming and AI/ML |
| 02 | `02-Python-Execution.ipynb` | How Python code runs, executing statements, and working with Python environments |
| 03 | `03-Installing-Python.ipynb` | Python installation, version checking, and environment setup |
| 04 | `04-Type-Casting.ipynb` | Converting between data types, implicit conversion, and explicit conversion |
| 05 | `05-Comments.ipynb` | Single-line comments, multiline documentation conventions, and code readability |
| 06 | `06-Operator.ipynb` | Arithmetic, comparison, logical, assignment, identity, and membership operators |
| 07 | `07-Input-And-Output.ipynb` | `print()`, `input()`, formatted output, and handling user input |
| 08 | `08-Conditional-Statements.ipynb` | `if`, `elif`, `else`, nested conditions, and decision-making |

> **Note:** The topics above describe the intended coverage based on the notebook names. Keep the actual filenames unchanged and update this table if the notebook contents differ.

## 🎯 How to Use These Notebooks

1. Open a notebook in Jupyter Notebook or VS Code.
2. Read the explanations before running the code.
3. Execute each code cell in order.
4. Change the inputs and experiment with the examples.
5. Add your own examples to test your understanding.
6. Solve related exercises in the `02-Basic-Tasks/` and `03-Topic-Wise-Practice/` folders.

## 🛠️ Requirements

- Python 3
- Jupyter Notebook or Jupyter support in VS Code

If Jupyter is not installed in your active Python environment, install it with:

```bash
python -m pip install notebook
```

Then launch Jupyter Notebook with:

```bash
jupyter notebook
```

Alternatively, open the `.ipynb` file directly in VS Code if the required Python and Jupyter extensions are installed.

## 💡 Learning Tips

- Do not just run the cells; predict the output before execution.
- Experiment with incorrect inputs to understand errors.
- Revisit earlier notebooks when a later concept depends on them.
- Keep notes about confusing concepts and common mistakes.
- Practice writing short programs without referring to the examples.
