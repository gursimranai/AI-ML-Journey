## 🎯 Learning Objectives

- Strengthen understanding of individual Python concepts.
- Improve logical reasoning and problem-solving ability.
- Practise writing programs independently.
- Learn to test solutions using different inputs.
- Recognize common errors and improve debugging skills.
- Build confidence before moving to larger programming projects.

## 🧠 Recommended Practice Method

1. Review the relevant concept before starting.
2. Read each problem carefully and identify its requirements.
3. Write your solution without immediately checking external answers.
4. Run your code and test normal, boundary, and invalid inputs where appropriate.
5. Compare your approach with alternative solutions when available.
6. Refactor your code for readability and simplicity.
7. Revisit problems that you could not solve independently.

**Tip:** If you need to look at a solution, close it afterward and try implementing the solution again from memory. This helps you check whether you understand the underlying logic.

## 💡 Good Coding Practices

- Use meaningful variable and function names.
- Break complex problems into smaller steps.
- Avoid unnecessary repetition.
- Prefer readable code over clever but confusing shortcuts.
- Test edge cases rather than checking only one example.
- Add explanations when they clarify a non-obvious approach.
- Keep solutions consistent with the concepts being practised.
