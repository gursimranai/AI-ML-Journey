# 📝 Python Basic Tasks

This folder contains beginner-level Python programming tasks collected from external learning resources, including online courses and educational platforms, to support hands-on practice.

These exercises help reinforce fundamental Python concepts through practical coding. Where available, task notebooks and their corresponding answer notebooks are kept separately so that problems can be attempted independently before reviewing solutions.

## 🎯 Purpose

- Practise Python fundamentals through coding exercises.
- Improve problem-solving and logical thinking.
- Apply concepts learned in the fundamental notebooks.
- Compare independent attempts with available solutions.
- Identify mistakes and reinforce concepts through repetition.

## 📚 How to Use This Folder

1. Open a task notebook without answers.
2. Read the problem statement and identify the relevant concepts.
3. Write and run your own solution.
4. Test your solution with different inputs.
5. Review the corresponding answer notebook, if available.
6. Compare the approaches and understand any differences.
7. Record useful lessons and revisit difficult problems.

**Recommendation:** Attempt each task independently before opening its answer notebook. Understanding why a solution works is more valuable than simply copying it.

## 🌐 Sources and Attribution

Some exercises and learning materials in this folder are obtained from external courses, educational websites, or other learning resources.

Whenever possible, document the following for each external resource:

- **Source:** Course, platform, instructor, or author.
- **Original URL:** Link to the original resource.
- **License or permissions:** Terms governing redistribution and reuse.
- **Modifications:** Any changes made to the original material.
- **Solutions:** Clearly distinguish your own solutions from solutions supplied by the original source.

If the source is not yet identified, record it as *source to be verified* rather than inventing a citation.

### Copyright and Redistribution

Public availability does not automatically mean that a course notebook or assignment can be redistributed publicly.

- Check the source's license and reuse permissions before publishing downloaded notebooks.
- Preserve required attribution and copyright notices.
- Do not remove an author's attribution or present their original solutions as your own.
- If redistribution is not permitted, consider replacing the downloaded material with your own independently written problem descriptions and linking to the original source instead.
- Keep third-party material separate from your original notes and solutions where practical.

## 💡 Practice Guidelines

- Prefer clear, readable, and well-structured code.
- Use meaningful variable names.
- Test normal cases and edge cases.
- Avoid relying exclusively on memorized answers.
- Rewrite a solution in your own words and code when practising independently.
- Keep a record of concepts that need revision.
