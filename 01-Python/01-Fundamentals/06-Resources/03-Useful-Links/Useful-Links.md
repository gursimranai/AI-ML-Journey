## 7. 🧭 Recommended Learning Workflow

1. Study a concept in your Python notebook.
2. Consult the official documentation for clarification.
3. Write and run your own examples.
4. Solve related exercises independently.
5. Record mistakes and important lessons.
6. Apply the concept in a small project.
7. Commit meaningful progress to GitHub.
