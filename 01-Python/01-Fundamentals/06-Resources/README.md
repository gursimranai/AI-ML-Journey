# 📚 Python Resources

This folder contains reference materials that support learning and practicing Python fundamentals. These resources are intended to make revision easier, clarify terminology, and provide useful references while working through notebooks, exercises, and projects.

## 📂 Folder Contents

| File | Description |
|---|---|
| `Python-Cheatsheet.md` | A quick reference for Python syntax, operators, built-in data types, control flow, collections, functions, and other fundamental concepts. |
| `Python-Glossary.md` | Definitions of important Python terms, concepts, and programming vocabulary. |
| `Useful-Links.md` | A curated collection of useful Python documentation, tutorials, and learning resources. |

## 🎯 How to Use These Resources

- **During learning:** Consult the glossary when a term or concept is unfamiliar.
- **During coding:** Use the cheatsheet to quickly recall syntax and common patterns.
- **During revision:** Review important concepts before assessments and practice sessions.
- **During problem-solving:** Refer to official documentation when you need a detailed explanation.
- **During project development:** Use these references to reinforce correct Python practices.

## 📌 Resource Guidelines

- Prefer official documentation and reliable educational sources.
- Keep explanations concise, accurate, and beginner-friendly.
- Organize information with headings, tables, and code examples where helpful.
- Verify external links periodically.
- Attribute third-party resources and respect their licenses and copyright.
- Update these files when new concepts are added to the learning repository.
