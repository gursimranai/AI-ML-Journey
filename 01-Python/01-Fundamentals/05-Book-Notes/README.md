# 📚 Python Book Learning

This folder organizes book-based Python learning materials that complement the notebooks, exercises, and practical work in this repository.

Books provide structured explanations of programming concepts and can help develop a deeper understanding of Python, from its fundamentals to more advanced language features.

The goal of this section is to maintain personal study notes, original code examples, experiments, and concept summaries while learning from technical books.

## 📂 Folder Structure

```text
05-Book-Learning/
├── README.md
├── 01-Learning-Python/
├── 02-Novice-Python/
└── 03-Fluent-Python/
```

Each book folder can contain its own README, reading notes, code examples, and practice exercises as needed.

## 📖 Learning Resources

### 1. Learning Python

**Folder:** `01-Learning-Python/`

Use this section to study Python syntax, core language features, data types, functions, and other foundational concepts.

### 2. Novice Python

**Folder:** `02-Novice-Python/`

Use this section to organize beginner-oriented reading notes and practical examples that reinforce Python programming fundamentals.

### 3. Fluent Python

**Folder:** `03-Fluent-Python/`

Use this section to explore more advanced Python concepts, idiomatic programming patterns, data model behavior, iteration, functions, and other topics covered by the book.

The depth and order of study should follow the edition and contents you are actually using.

## 🎯 Recommended Study Workflow

1. Read a small section of the book.
2. Write a concise summary in your own words.
3. Implement the relevant concepts in Python.
4. Experiment with the examples and modify them.
5. Record questions, mistakes, and important observations.
6. Connect the concepts to your notebooks and practice exercises.
7. Review the notes before moving to the next topic.

## 📝 Suggested Organization for Each Book

```text
book-folder/
├── README.md
├── Notes/
├── Examples/
└── Exercises/
```

This is an optional structure. Use it only when it helps organize your actual work; avoid creating empty folders unnecessarily.

## 💡 Study Best Practices

- Focus on understanding concepts instead of copying code.
- Run examples and test variations yourself.
- Explain important ideas in your own words.
- Keep examples small and easy to reproduce.
- Record the book title, author, and edition for reference.
- Link related notebooks or projects where useful.

## ⚖️ Copyright and Attribution

Books and their accompanying materials may be protected by copyright.

- Write original summaries and explanations.
- Create your own code examples and exercises.
- Credit the book and author when referencing their work.
- Avoid publishing full chapters, scanned pages, or substantial copied passages without permission.
- Check the book's license before redistributing accompanying code or datasets.
- Link to legitimate publisher or author resources where appropriate.

This repository is intended for educational use and should distinguish original learning notes from third-party material.
