## 🎯 Learning Objectives

- Understand and apply fundamental Python concepts.
- Convert problem statements into working programs.
- Develop logical reasoning and structured problem-solving skills.
- Write readable and maintainable Python code.
- Test solutions using different inputs and examine their outputs.

## 🧠 Recommended Workflow

1. Read the original question paper carefully.
2. Attempt each question independently before viewing the solution.
3. Implement the solution in Python.
4. Run the code and verify the output.
5. Review the explanation and test additional cases.
6. Revisit difficult questions to strengthen your understanding.

## 📌 Repository Guidelines

- Keep each assignment's PDF, README, and solutions together.
- Preserve the original question paper.
- Maintain the question order in `Solutions.ipynb`.
- Use Markdown cells to explain the logic and code cells to implement solutions.
- Add new assignments as separate numbered folders.
