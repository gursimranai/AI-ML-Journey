# 📝 Assignment 01 — Python Fundamentals

## 📌 Overview

**Assignment 01** focuses on the fundamentals of Python programming, helping build a strong foundation in writing simple programs, accepting user input, performing calculations, and making decisions using conditional statements.

The original questions are available in `Assignment.pdf`, and their solutions are organized in `Solutions.ipynb`.

## 🎯 Topics Covered

| Topic | Concepts |
|---|---|
| Input and Output | `input()`, `print()`, displaying messages and results |
| Variables | Variable assignment, naming rules, storing values |
| Data Types | Basic types such as `int`, `float`, `str`, and `bool` |
| Type Conversion | Converting user input into numeric or other data types |
| Operators | Arithmetic, comparison, logical, and assignment operators |
| Conditional Statements | `if`, `elif`, `else`, nested conditions |
| Basic Problem Solving | Combining multiple concepts to solve programming questions |

## 📂 Assignment Files

- 📄 [Original Assignment PDF](Assignment.pdf) — contains the original questions.
- 📓 [Solutions Notebook](Solutions.ipynb) — contains solutions arranged in question order.

## 💻 Recommended Workflow

1. Read the question carefully and identify the expected input and output.
2. Identify the Python concepts required to solve the problem.
3. Attempt the solution independently before checking any reference.
4. Run the code and verify the output using suitable test cases.
5. Review the solution and understand why it works.
6. Record any mistakes or concepts that need revision.

## ✅ Learning Outcomes

After completing this assignment, the learner should be able to:

- Write basic Python programs using variables and data types.
- Accept input from users and display formatted output.
- Perform calculations using appropriate operators.
- Convert input values into the required data types.
- Use conditional statements to implement decision-making logic.
- Develop a systematic approach to solving beginner-level programming problems.
