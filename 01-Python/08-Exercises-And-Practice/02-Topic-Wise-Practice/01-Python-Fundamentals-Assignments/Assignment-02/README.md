# 📝 Assignment 02 — Decision-Making and Loops in Python

## 📌 Overview

**Assignment 02** focuses on decision-making and looping constructs in Python. It builds on the fundamentals learned in Assignment 01 and develops the ability to control program execution, repeat operations, and solve problems using logical conditions.

The original questions are available in `Assignment.pdf`, and their solutions are organized in `Solutions.ipynb`.

## 🎯 Topics Covered

| Topic | Concepts |
|---|---|
| Conditional Statements | `if`, `elif`, `else`, nested conditions |
| Decision-Making | Selecting actions based on conditions |
| Multiple-Branch Logic | Handling multiple possible cases |
| `match-case` | Pattern-based branching in Python 3.10 and later |
| `for` Loops | Iterating over sequences and using `range()` |
| `while` Loops | Repeating code while a condition remains true |
| Loop Control | `break`, `continue`, and `pass` |
| Nested Loops | Using loops inside other loops |
| Problem Solving | Combining conditions and loops to solve programming questions |

> **Note:** Python does not have a traditional `switch` statement. The `match-case` statement, introduced in Python 3.10, provides pattern matching for many branching scenarios. Some problems can also be solved using `if-elif-else`.

## 💻 Recommended Workflow

1. Read each question and identify the required output.
2. Determine whether the problem requires a condition, a loop, or both.
3. Write the solution independently before referring to other implementations.
4. Test different inputs, including boundary cases.
5. Check loop termination conditions to avoid infinite loops.
6. Review the code for correctness, readability, and unnecessary repetition.
7. Record mistakes and revisit the concepts that need improvement.

## ✅ Learning Outcomes

After completing this assignment, the learner should be able to:

- Implement decision-making logic using conditional statements.
- Handle multiple conditions and alternative execution paths.
- Use `match-case` when appropriate for supported Python versions.
- Apply `for` and `while` loops to repetitive tasks.
- Control loop execution using `break` and `continue`.
- Understand nested loops and their execution flow.
- Combine conditions and loops to solve beginner-level programming problems.
