# 📚 Topic-Wise Practice

This directory contains Python practice material organized around programming topics. It helps reinforce concepts learned in the Python fundamentals notebooks through hands-on exercises, university assignments, and practical problem-solving.

## 📂 Directory Structure

```text
02-Topic-Wise-Practice/
├── README.md
│
└── 01-Python-Fundamentals-Assignments/
    ├── README.md
    │
    ├── Assignment-01/
    │   ├── README.md
    │   ├── Assignment.pdf
    │   └── Solutions.ipynb
    │
    └── Assignment-02/

        ├── Assignment.pdf
        └── Solutions.ipynb
```

### 📁 Folder Overview

| File or folder | Description |
|---|---|
| `Python-Fundamentals-Assignments/` | Groups assignments covering Python fundamentals. |
| `Assignment-01/` | Contains the assignment covering basic input/output and conditional statements. |
| `Assignment-02/` | Contains the assignment covering decision-making and loops. |
| `Assignment.pdf` | Original assignment question paper. |
| `Solutions.ipynb` | Question-by-question answers, code, explanations, and outputs. |
| `README.md` | Describes the assignment, topics covered, and links to its solutions. |

## 🎯 Objectives

- Strengthen understanding of Python fundamentals.
- Apply programming concepts to assignment questions.
- Improve logical reasoning and problem-solving skills.
- Develop readable, maintainable Python code.
- Review mistakes and understand the reasoning behind solutions.

## 🧠 Recommended Workflow

1. Review the concepts relevant to the assignment.
2. Attempt each question independently.
3. Write and execute the solution in Python.
4. Test the solution with suitable inputs.
5. Review the explanation and output in the notebook.
6. Revisit questions that require additional practice.

## 📌 Organization Guidelines

- Keep the original assignment PDF unchanged.
- Maintain the same question order as the original paper.
- Explain each answer in the corresponding notebook section.
- Keep each assignment's README, PDF, and solutions together.
- Add new assignments as separate folders.
- Use this directory for topic-focused practice and assignments; keep broader mathematics, data science, and machine learning practice in the repository's `12-Practice/` section.
