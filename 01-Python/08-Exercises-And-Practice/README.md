## 🎯 Learning Objectives

- Strengthen Python fundamentals through regular coding practice.
- Apply concepts such as variables, operators, conditions, loops, strings, collections, and functions.
- Develop logical reasoning and algorithmic thinking.
- Practice solving questions independently before checking solutions.
- Complete university assignments in an organized, traceable format.
- Improve code readability, debugging, and testing habits.
- Prepare for academic assessments, technical interviews, and future AI/ML development.

## 🔄 Recommended Practice Workflow

1. **Understand:** Review the concept required to solve a question.
2. **Attempt:** Write your own solution without immediately checking the answer.
3. **Test:** Run the code with normal, boundary, and invalid inputs where appropriate.
4. **Debug:** Identify the cause of errors and correct them.
5. **Review:** Compare your approach with alternative solutions.
6. **Document:** Record important observations, mistakes, and concepts learned.
7. **Revise:** Reattempt difficult questions after some time without looking at the solution.

## 📝 Assignment Organization

University assignments are stored under `02-Topic-Wise-Practice/Python-Fundamentals-Assignments/`.

Each assignment has its own folder containing:

- `README.md` — assignment overview and topic coverage.
- `Assignment.pdf` — original assignment questions.
- `Solutions.ipynb` — solutions arranged in the same order as the questions.

Solutions should include the question number, Python code, a brief explanation, and sample output wherever useful. Original assignment documents should remain unchanged.

## 💡 Practice Guidelines

- Prefer understanding the solution over memorizing code.
- Use meaningful variable and function names.
- Follow Python naming conventions and maintain consistent indentation.
- Test edge cases instead of relying on a single example.
- Avoid copying solutions before making a genuine attempt.
- Keep practice material organized and use Git commits to track meaningful progress.
- Revisit mistakes and solve similar questions to strengthen understanding.
